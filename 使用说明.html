AI 教学工作台 · 使用说明

你不需要跑任何脚本——所有能力都在对话里调用。你只需用大白话说需求，AI 自动调底库、生成器、话术库帮你出结果。

1四大核心能力 · 对话式用法

下面是你日常会用的四个动作。每条都给了「你怎么说 → AI 怎么做 → 你得到什么」。直接照着在对话里说就行。

① 生成学生专属教学大纲

把学生的年级、层次、学期、家长期望、漏洞告诉 AI，它调大纲底库 + 生成器，输出带裁剪说明的 xlsx。

💬 你这样说帮张同学生成专属大纲，初二·精进·寒假，家长期望查漏优先，漏洞是含参不等式组、一次函数综合、分式方程。
✅ 你得到一份 xlsx：漏洞讲次自动前置、每讲有裁剪说明、重点★标注、未覆盖漏洞给出跨年级补课建议（如「含参不等式组」→查到初一好学/精进寒假里有）。可直接编辑打印。
能调的全部底库：FY26寒春（初一~初三 × 好学/精进，寒+春）、FY27暑秋（含志高+壮志拔高），共 564 讲结构化数据。
② 生成家长沟通话术

三个场景：课后反馈、家长提问应答、阶段规划。AI 从学生档案调数据填充变量，话术风格对齐你的[玫瑰]范例。

💬 课后反馈这样说帮张同学写课后反馈，今天讲了一次函数综合，孩子反应快但联立计算易错、分类讨论不全，后续安排一讲强化含参分类讨论。
💬 家长提问应答这样用把家长发来的话直接转给 AI，比如「孩子上了这么久怎么没提分」，并说明是哪个学生。
✅ 你得到对齐你风格的话术，家长提问应答会自动调出该生成绩曲线作依据，给出 2-3 版回复思路 + 可复制话术。

覆盖的家长提问类型：为什么没提分 / 能不能加课 / 孩子是不是不适合 / 作业做不完 / 下次能考多少分。新类型随时告诉我补充入库。

③ 学情诊断（试卷→漏洞+提分方向）

把学生试卷失分情况告诉 AI，它对照大纲知识点体系出结构化诊断报告，并自动建议切入讲次。

💬 你这样说张同学初二精进，这次月考102分，失分在含参不等式组-6、一次函数综合-8、反比例k几何-4，帮我分析漏洞和提分方向。
✅ 你得到诊断报告：漏洞清单（致命/薄弱/熟练）+ 失分模块统计 + 提分方向 + 建议切入大纲讲次，可直接写入学生档案。
④ 学生档案（记住每个学生各阶段）

把课堂表现、成绩、家长沟通要点发给 AI，它记入该学生档案（多 sheet：总览/诊断/成绩/课堂/沟通/阶段目标），随用随调。

💬 你这样说记一下：张同学今天第11讲反比例函数二，亮点是k几何意义理解到位，问题是与一次函数综合时交点算错，反馈已发。
✅ 你得到更新后的学生档案，下次说「调张同学档案」即可一眼看清他各阶段情况，不用翻聊天记录。

2工作台文件清单

所有文件都在 AI教学工作台/ 目录下，结构如下：

AI教学工作台/ ├─ AI教学工作台蓝图.html // 整体设计方案（9模块/架构/路线） ├─ 使用说明.html // 本文件 ├─ 大纲底库/ │ ├─ syllabus_library.json // 564讲结构化底库（生成器燃料） │ └─ parse_syllabus.py // 底库解析脚本（底库有更新时重跑） ├─ 专属大纲生成器/ │ ├─ generate_syllabus.py // 生成器（命令行可跑，也供AI调用） │ └─ output/张同学_初二精进_寒假专属大纲.xlsx // 示例产出 ├─ 话术库/ │ ├─ 话术手册.html // 话术手册（可查阅） │ └─ 话术模板库.json // 结构化话术库（AI调用） └─ 学生档案/ ├─ 学生档案模板.xlsx // 6-sheet档案模板（含示例） ├─ 学情诊断报告模板.xlsx // 诊断报告表单模板 └─ generate_templates.py // 模板生成脚本

3后续演进（二期/长期）

MVP 已跑通「记得住学生 + 出得了大纲 + 写得了话术 + 看得准漏洞」。后续可加：

二期（备课+提醒）

课前备课助手（教案/出入门测/练习/作业四件套）、课表智能提醒（提前1天+提前10分钟到岗）、课堂表现自动归档、话术模板自定义保存。

长期（数据沉淀）

成绩进步看板（曲线+雷达）、题库与错题本（按知识点/难度归集）、续班满意度预警、跨学生薄弱统计反哺备课。

需要哪个二期能力，直接说「帮我加备课助手」或「配置上课提醒」，我接着搭。

4几点说明

关于资料库上传：当前环境把文件上传到 WorkBuddy 资料库受限（返回 path not allowed），所以底库和模板暂存在工作台目录。如需跨设备访问，你可在 WorkBuddy 界面手动上传这几个文件到资料库，或后续我协助处理权限。
关于钉钉群：按你的确认，钉钉群消息用「粘贴兜底」——你把群里家长消息或考试通知复制给我即可，无需 API。
关于试卷脱敏：按你的确认，试卷走 AI 识别时我会脱敏处理（隐去姓名/学校/考号等），只保留题目与失分用于分析。
关于大纲底库更新：机构下发新大纲时，把新 xlsx 给我，我重跑 parse_syllabus.py 更新底库，生成器自动用新版。
